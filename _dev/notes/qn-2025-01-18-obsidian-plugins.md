# Quick Note: Obsidian Community Plugins Setup

Created: 2025-01-18

## Context

## Content

Recommended community plugins for CAIRN vault setup.

### Required Plugins

**Dataview**
- Enable JavaScript Queries: ✓
- Enable Inline JavaScript Queries: ✓
- Purpose: Dashboard queries, task views, update checker

**Templater**
- Template folder location: `_CAIRN/templates`
- Purpose: File creation with consistent structure

**Tasks**
- Just enable (use default settings)
- Purpose: Task management and checkboxes

### Development Only

**Obsidian Git**
- For CAIRN-dev vault only
- Auto-backup to private repository
- Not needed for end users
