# Idea: Daily task review automation

**Captured:** 2026-06-24 09:15

## Key Points
- Current process: Manual review of tasks across areas/projects each morning
- Takes 10-15 minutes to check what's due, what's blocked, what's waiting
- Could automate with a daily digest script

## Potential Implementation
- Python script using Obsidian Dataview or direct markdown parsing
- Run via cron job each morning at 7 AM
- Generate markdown summary:
  - Overdue tasks (any track)
  - Due today/this week
  - Blocked/waiting status (so I can follow up)
  - Recent completed (for motivation)
- Output to daily note or email

## Decisions
None yet - need to think through whether automation is worth the setup time. Manual review does force me to engage with the system.

## Why Captured
Had this thought during morning review when I realized I was doing the same query pattern every day. Might be worth automating, might not. Want to track the idea.

## Notes
Pros of automation:
- Consistent review every day
- Don't forget to check certain areas
- Quick overview without opening vault

Cons:
- Setup time (probably 2-3 hours)
- Maintenance if vault structure changes
- Might reduce engagement with the system

Should revisit this after using current manual process for 1-2 more months. If it still feels repetitive, worth the automation investment.
