## Overview
Cloud-based design and prototyping tool. Used for creating detailed office layout plans with accurate measurements and visualization before purchasing furniture.

## Details
**Account Type:** Free tier (sufficient for personal projects)

**Key Features Used:**
- Precise measurement tools
- Component library for furniture
- Real-time preview
- Share links for contractor review
- Mobile app for on-site reference

**Capabilities:**
- 2D floor planning
- Furniture placement mockups
- Measurement annotations
- Color and material testing
- Export to PDF for contractors

**Access:**
- Web: figma.com
- Desktop app: Available for Mac/Windows
- Mobile: iOS/Android apps

## Usage
**Home Office Project:**
- Created detailed room layout with measurements
- Tested 3 different furniture arrangements
- Annotated electrical outlet placements
- Shared design with Mike (contractor) for review
- Exported measurements for furniture ordering

**Project File:**
https://figma.com/file/abc123/home-office-layout

**Benefits:**
- Caught measurement issues before ordering
- Visualized desk placement vs. window glare
- Mike could review electrical plan remotely
- Easy to adjust and iterate on designs

## Notes
Figma's free tier has been more than adequate for this home project. The component library had pre-made furniture elements that matched real products, which made layout planning accurate.

The mobile app was particularly useful for on-site verification - could pull up the design while standing in the room to confirm measurements.

**Learning Curve:**
Minimal - watched 2 YouTube tutorials and was productive within an hour. Interface is intuitive for basic layout work.

**Alternatives Considered:**
- SketchUp: More powerful but overkill for 2D layouts
- Paper sketches: Not precise enough for furniture ordering
- PowerPoint: Measurements not accurate

Figma struck the right balance of power and simplicity for this use case.
