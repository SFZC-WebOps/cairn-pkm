# Slack

**Version:** Enterprise Grid  
**Website:** https://slack.com

## Usage

Primary communication tool for:
- Team messaging (replaces email for internal quick questions)
- Project channels
- Department coordination
- Announcements
- File sharing
- Integration with other tools (Google Calendar, Asana, etc.)

## Tips & Best Practices

**Response expectations:**
- Urgent: @mention person directly
- Non-urgent: Post in channel, check periodically
- After hours: Use DM sparingly, respect work-life balance

**Channel hygiene:**
- Use threads for detailed discussions
- Pin important messages
- Update channel descriptions
- Archive inactive channels

**Integrations we use:**
- Google Calendar (meeting reminders)
- Google Drive (file previews)
- Asana (project updates)

## Common Issues & Solutions

**Issue:** Too many notifications  
**Solution:** Customize notification settings per channel, use "Do Not Disturb" mode

**Issue:** Can't find old message  
**Solution:** Use search with filters (from:person, in:channel, during:date)

**Issue:** Need to share with external person  
**Solution:** Use Slack Connect or fall back to email
