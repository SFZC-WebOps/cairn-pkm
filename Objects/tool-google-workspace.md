# Google Workspace

**Purpose:** Email, calendar, documents, and collaboration suite  
**Version:** Business Standard  
**Website:** https://workspace.google.com  
**Domain:** example.org

## Services Included

- **Gmail** - Email (@example.org addresses)
- **Google Calendar** - Scheduling and meetings
- **Google Drive** - File storage and sharing
- **Google Docs/Sheets/Slides** - Document creation
- **Google Meet** - Video conferencing
- **Google Chat** - (Not used - we use Slack instead)

## Access & Accounts

**Admin:** IT Director  
**Account Type:** Business Standard  
**Users:** 45 licenses  
**Monthly Cost:** $540 ($12/user)  
**Storage:** 2TB per user  
**Contract:** Annual, renews July 2025

## Organization Structure

- `Sales` - Sales collateral and proposals

- `Finance` - Financial reports (restricted access)

**Key Files:**
- Employee Directory (Company Resources)
- Expense Report Templates (Finance)
- Meeting Room Calendars (Company Resources)

## Best Practices

**Email:**
- Use descriptive subject lines
- CC only when necessary
- Use BCC for large group emails
- Set up email signature with contact info

**Calendar:**
- Book conference rooms via room calendars
- Set working hours in calendar settings
- Mark personal time as "Out of Office"
- Accept/decline meeting invites promptly

**Drive:**
- Store work files in Shared Drives (not My Drive)
- Use clear folder structures
- Share links instead of attachments when possible
- Check sharing permissions before distributing

## Common Issues & Solutions

**Issue:** Calendar not syncing on phone  
**Solution:** Remove and re-add account in phone settings

**Issue:** Can't access shared file  
**Solution:** Request access from file owner, check if link expired

**Issue:** Meeting link not working  
**Solution:** Ensure Meeting is enabled in Calendar event, regenerate link

## Migration to New Office

**Considerations:**
- Email addresses stay the same (no changes needed)
- Conference room calendars need to be updated with new room names
- Update email signatures with new office address
- Test video conferencing bandwidth in new space
